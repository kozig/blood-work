Welcome to Blood Work Analysis Demo

This is a demonstration application showing how to integrate the bloodwork package into a Flask web application.

Features

  • ✅ Upload and parse blood work PDF reports (LifeLabs format)
  • ✅ Store results in database (SQLite for demo)
  • ✅ View all test results with filtering
  • ✅ Identify abnormal (out-of-range) tests
  • ✅ Trend analysis over time
  • ✅ Interactive dashboard with visualizations

About This Demo

This demo application uses SQLite for simplicity. In production, you would:

  • Use PostgreSQL or MySQL instead of SQLite
  • Implement proper authentication (not session-based)
  • Add HTTPS and security measures
  • Implement proper PHI handling and HIPAA compliance
  • Add role-based access control
