QUICK START (3 STEPS):
----------------------

STEP 1: Install pdfplumber

Run ONE of these commands:

    sudo apt update && sudo apt install python3-pip -y && pip3 install pdfplumber --user

    OR

    wget https://bootstrap.pypa.io/get-pip.py && python3 get-pip.py --user && pip3 install pdfplumber --user


STEP 2: Run the scraper

    python3 scrape_bloodwork_advanced.py


STEP 3: Check the output

    cat blood_work_extracted.csv


THAT'S IT!
----------

The script will:
  • Read: Reports_librepdf.pdf
  • Extract: All blood test results
  • Output: blood_work_extracted.csv
  • Show: Summary of findings


TROUBLESHOOTING:
----------------

If you get "No module named pdfplumber":

    pip3 install pdfplumber --user

If you get "pip: command not found":

    sudo apt install python3-pip -y

If you get "Permission denied":

    chmod +x scrape_bloodwork_advanced.py
